# Música y efectos

Los archivos de audio no están en el repositorio. El juego funciona sin ellos
(se juega en silencio); para tener sonido, copiá acá estos archivos:

| Archivo | Dónde suena |
|---|---|
| `musica_menu_1.wav` | Menú principal y pantalla de resultados |
| `ambiente.wav` | Ingreso de nombre y nivel 2 |
| `musica-niveles_2.wav` | Nivel 1 |
| `musica_nvl.wav` | Nivel final (jefe) |
| `sonido disparo.mp3` | Disparos |
